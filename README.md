This project is part of my academic work and focuses on using Convolutional Neural Networks (CNNs) to detect and classify tomato leaf diseases from images. 
The aim is to provide an automated and accurate method to assist in early diagnosis.
Tomato plants are vulnerable to various diseases that can significantly affect yield and quality. 
Traditional diagnosis methods are often time-consuming and prone to human error. In this project, I trained a deep learning model on a dataset of tomato leaf images to automatically identify common diseases.


Results:

In this project i made 4 custom models(best accuracy 98%) and 3 transfer learning models (best accuracy 99%).
Evaluated using training/validation/test splits with metrics like accuracy and confusion matrix.
